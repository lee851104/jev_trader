# Jev SPY 模擬交易工具設計

日期：2026-09-25
狀態：已實作並完成離線驗證（含 buy／sell／hold）；真實供應商呼叫尚未實測。

## 目的與已確認範圍

建立可放入履歷、可實際操作的 Python 小專案：使用 TypeSafe Jev 對 SPY 歷史行情做買入、賣出、持有決策，透過中文本機網頁展示決策、模擬成交與完整紀錄。

SPY 為追蹤 S&P 500 的 ETF。初始資金 10,000 美元，每次最多交易一股，不借款、不放空。模型僅看到截至決策日的最近 20 筆日線與當時帳戶資料。成交使用下一交易日開盤價加上設定的滑價與手續費。

這是歷史重播的工程展示，不是獲利能力驗證；即使不把未來行情送入模型，模型訓練資料仍可能含歷史事件。不得宣稱回測完全排除模型記憶造成的偏差。

## 整合方式

在現有 Python 套件新增獨立 `jev_ultrafast/trading/` 模組與 `jev-trader` 啟動指令。沿用 Python 標準函式庫與現有 httpx，使用本機 HTTP 服務與 HTML/CSS/JavaScript 介面，降低新依賴和學習負擔。

原有瀏覽器 Agent 與 `jev` 指令保持原有用途。交易是 Jev 決策的另一個應用，不把交易硬塞入瀏覽器操作模型，也不需要文字生成模型或 OpenAI API。

模組責任：
- 資料：下載、匯入、驗證及保存日線。
- 決策：建立 Jev 輸入，驗證輸出，記錄實際呼叫。
- 帳戶：決策、待成交、成交、拒絕與期末估值。
- 紀錄：保存每一步，提供 JSON/CSV 匯出。
- 服務與介面：中文操作面板、状态、績效曲線、決策及成交明細。

## 資料與模式

正式行情來源為 Alpha Vantage `TIME_SERIES_DAILY`、`symbol=SPY`、`outputsize=compact`，取得最近 100 筆日線；下載後快取本機。另提供固定欄位 CSV 匯入。資料需包含日期、開高低收、成交量；驗證日期唯一且遞增、價格正值且有限、成交量非負、OHLC 範圍合理，至少 21 筆。

介面分別標示資料來源和決策來源：
- 離線展示：內建明確標記的合成行情與固定規則模型；不是 SPY 真實行情，也不是 Jev 證據。
- Jev 模式：真實行情或使用者匯入資料配合真實 TypeSafe API。缺少必要金鑰就提示設定，不靜默改用假模型。

原始日線不含完整股息和拆股事件。第一版顯示「未調整行情／未計股息的模擬結果」，不稱為總報酬回測。使用期間若含拆股，該結果不適合解讀為績效；支援公司行動會是後續功能。

## 畫面與使用流程

單頁中文介面：
1. 顯示 SPY、資料來源、日期範圍及決策模式。
2. 取得行情或載入示例；建立新的模擬帳戶。
3. 「執行決策」：只處理目前收盤日，顯示模型結果與待成交狀態。
4. 「推進下一交易日」：處理開盤成交與当日收盤估值。
5. 顯示現金、股數、資產總值、資產曲線、模型呼叫數及決策耗時。
6. 查看與匯出模型輸入、輸出、規則檢查及成交紀錄。

支援手動逐步操作，以及使用者於 2026-09-25 追加的一鍵自動執行：每批最多推進 5 個交易日、最多 5 次 Jev 請求，可停止。流程、選項與資產曲線同步顯示；請求循序執行，不重試。停止會等目前操作完成，頁面重新載入不自動續跑。不新增自動下真實訂單、券商登入或區塊鏈功能。

## 決策與成交規則

在第 20 筆日線收盤後開始做第一個決策。每個收盤日最多建立一個已接受的決策；重複點擊不重複扣款或發送成功過的決策請求。

Jev 決策只有三種：`buy`、`sell`、`hold`，介面分別顯示「買入」、「賣出」、「持有」。API 決策值與紀錄統一使用小寫。保存原始模型選擇與執行結果，不能把被拒絕的 `buy` 改成 `sell` 並保留原機率。機率不是獲利保證，不另生成模型未提供的理由。

模型輸出需驗證選項、機率、數值有限性及欄位型別。錯誤、逾時、空回應都停在當前步驟並顯示錯誤，不自動重送付費請求。

`buy`（買入）：成交成本為隔日開盤價加買方滑價及固定手續費，隔日重新檢查現金是否足夠，不足則拒絕。
`sell`（賣出）：必須持有至少一股；收入為隔日開盤價扣賣方滑價及手續費，拒絕會造成負現金的交易。
`hold`（持有）：維持目前現金與持股，不交易、不收取交易費用，仍可推進日期。零持股時維持零持股，不強制買入。

手續費及滑價在開始時固定，預設每筆 1 美元及 1 個基點，明確標示為使用者可調的模擬假設。金額使用 Decimal 計算並定義四捨五入規則。帳戶總值為現金加持股乘當日收盤價；最後一日無隔日開盤，不再產生新訂單。

## 紀錄與安全

金鑰仅存伺服器環境或忽略的 `.env`：沿用 `TYPESAFE_API_KEY`、`TYPESAFE_MODEL`，新增 `ALPHAVANTAGE_API_KEY`。不在網頁、匯出檔或錯誤訊息暴露金鑰。

只綁定 127.0.0.1，採 Host/Origin 檢查及隨機操作 token；禁止任意 URL 或檔案路徑存取，限制匯入大小。匯入內容以文字安全呈現。

每次執行保存識別碼、資料雜湊、來源、起始設定、決策日、模型名稱、請求內容、回應、耗時、嘗試次数、訂單與帳戶快照。寫入失敗需阻止後續交易；模型請求開始前先記錄嘗試，結果不明時不得自動重送。重啟後第一版可查看或匯出紀錄，活動中的模擬需重新開始，不自動恢復或再次呼叫。

輸出存於忽略的 `artifacts/trading/`。README 清楚區分引用的上游專案、個人新增功能、離線驗證與實際 Jev 呼叫證據。

## 驗收

- 從本機介面完成載入資料、決策、隔日成交、查看與匯出紀錄。
- 測試證明模型輸入不含未來資料；下一日開盤成交、滑價、費用、資金不足、無持股賣出和最後交易日均正確。
- 測試資料驗證、API 格式錯誤、逾時、重複請求、紀錄寫入失敗及憑證遮蔽。
- 自動化測試使用 stub/httpx mock，不呼叫付費 API；離線展示明確標記。
- 執行 `uv run ruff check .`、`uv run pytest`、`node --check jev_ultrafast/static/app.js`、新交易 JS 語法檢查及 `uv build`。
- 在瀏覽器核對中文介面、操作流程、窄螢幕與失敗訊息。真實 Jev 與行情下載若未執行，交付時明確列出，不能用離線通過冒充。
