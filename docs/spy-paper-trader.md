# Jev Paper：美股模擬交易

以 Python 串接 TypeSafe Jev、歷史行情、模擬帳戶和中文介面的小型作品。只做模擬，不連接券商或送出真實訂單。

## 啟動

在專案資料夾執行：

```powershell
uv sync
uv run jev-trader
```

開啟 <http://127.0.0.1:8767>。服務僅綁定本機；按 Ctrl+C 停止。原本瀏覽器 Agent 仍使用 `uv run jev` 和 8766 埠。

## 第一次使用

1. 輸入美股或 ETF 代號，例如 `AAPL`、`NVDA`、`SPY`；小寫會轉大寫，`BRK.B` 會轉成 Yahoo 使用的 `BRK-B`。
2. 選「離線模擬」或「真實 Jev API」，點「載入行情」。預設下載 Yahoo 最近約三個月日線，排除下載當天 UTC 日期的資料，避免使用尚未完成的日線。畫面會標示實際最後日期；這不是即時報價。下載失敗保留原執行，不會改用另一檔股票。
3. 預設「最新行情判斷」使用最後 20 筆日線，按「讓 Jev 做決策」取得一次 buy／sell／hold 與結構化回應。沒有下一交易日資料，因此不模擬成交，也不提供自動重播。
4. 想觀察交易與損益，在「設定」切換「歷史重播」後重新載入。從第 20 筆開始，按「自動執行 5 天」依序決策與隔日模擬成交；也可手動逐步操作。每個新執行從本金 10,000 美元、零持股開始，不代表你的券商帳戶。
5. 「停止」會等目前操作完成再停止下一步；錯誤或最後一筆行情也會停止，不重試。自動執行需要保持頁面開啟，重新整理不會自行恢復。
6. 「即時總覽」以行情輸入 → Jev／規則選擇 → 模擬成交呈現可觀察流程；「代號行情」顯示日期、OHLCV、來源與模型可見範圍。歷史重播的未來資料不會送入當前模型請求。
7. 「決策回傳」可選日期，查看分類機率、confidence、模型版本、耗時、tokens、原始回應與模型輸入。查看紀錄不會呼叫模型；離線規則不產生 Jev 機率。
8. 行情按代號獨立快取；內附 SPY 歷史樣本與合成示例只適用 SPY。CSV 的標的須由匯入者確保與輸入代號一致，程式不會認證 CSV 所屬股票。

選擇模式只修改準備建立的新模擬，不會呼叫 API。按「載入行情」才建立新執行識別碼，舊紀錄保留；API 模式缺少金鑰時保留原模擬並顯示設定方式。按「讓 Jev 做決策」或「自動執行 5 天」才會發送付費推論。兩種模式都不連券商。

每次新建模擬都使用新識別碼，舊紀錄留在「歷史執行」。重啟服務不會自動繼續舊模擬或呼叫模型，但可以匯出舊紀錄。

### 決策定義

| API 值 | 中文 | 行為 |
| --- | --- | --- |
| `buy` | 買入 | 下一交易日嘗試買入一股 |
| `sell` | 賣出 | 下一交易日嘗試賣出一股已有持股 |
| `hold` | 持有 | 維持現金及持股；零持股也維持零持股，不收費 |

離線規則以最新收盤價相對五日均價決定：高於均價 buy，低於均價且有持股 sell，其餘 hold。
這個模型沒有 Jev 機率或實際推論耗時；畫面標示為規則模型並單獨計數。

### Jev 結構化回應

- `choice`：選中的分類，為 `buy`／`sell`／`hold`。
- `probabilities`：每個分類的機率，介於 0～1，總和為 1（可能有浮點誤差）。畫面保留回傳小數，不只顯示四捨五入的百分比。
- `confidence`：0～1，依機率分布的集中程度計算；不等於選中分類的機率。機率與 confidence 都不是獲利機率。

依據 [TypeSafe Choice 文件](https://docs.typesafe.ai/primitives/choice)。離線規則的 `probabilities`、`confidence` 為 `null`，代表未提供，不能當成 0 或虛構 Jev 機率。API 回應與程式整理的離線結果會分別標示。

## 使用真實行情與 Jev

若尚無 `.env`，先複製 `.env.example` 為 `.env`；如果已存在，編輯既有檔案，避免覆蓋原設定。
在本機編輯器填入以下名稱對應的金鑰，不要貼在公開程式碼或對話中：

```dotenv
TYPESAFE_API_KEY=
TYPESAFE_MODEL=jev-latest
ALPHAVANTAGE_API_KEY=
```

重新啟動服務。頁面只顯示「已設定／未設定」，不顯示金鑰本身。

- **Yahoo 日線**：預設來源，不需行情金鑰；檢查回傳代號、美元幣別、美國市場及股票／ETF 類別，資料不足或供應商拒絕時停止。
- **Alpha Vantage 日線**：另需 `ALPHAVANTAGE_API_KEY`，使用 Alpha Vantage `TIME_SERIES_DAILY` 的 compact 資料，通常為最近 100 筆；下载一次後可使用快取。供應商限流或權限錯誤會顯示下載失敗。
- **SPY 真實歷史樣本**：內附固定的 Yahoo Finance OHLCV 快照，不是即時行情，無須 Alpha Vantage 金鑰；可搭配離線規則或真實 Jev。採用供應商 `indicators.quote` 數值，沒有使用 `adjclose`，不承諾資料商完全未做任何拆股處理；模擬本身不計股息。
- **Jev 模型**：手動決策發送一個付費請求；每次點「自動執行 5 天」最多發送 5 次，已有待成交決策時先成交，不重新請求。請求循序執行，不重試；要繼續下一批需再次點擊。停止不會取消已送出的請求或費用。
- **規則模型搭配真實行情**：可以測試資料與交易流程，但仍不是實際 Jev 使用證據。
- **合成示例**：只允許規則模式，不能把它當真實 SPY 回測。

此功能不需要 `TEXT_MODEL_API_KEY` 或 OpenAI 金鑰。Jev 使用官方 systemone Choice API，而不是原版 Agent 的瀏覽器 click/type 選項。

來源：[TypeSafe API](https://docs.typesafe.ai/api)、[Choice](https://docs.typesafe.ai/primitives/choice)、
[Alpha Vantage 日線文件](https://www.alphavantage.co/documentation/#daily)、
[SPY 發行商介紹](https://www.ssga.com/us/en/individual/capabilities/spdr-core-equity-etfs/spy-sp-500)。

## CSV 格式

依日期從舊到新排列，至少 21 筆、最多 10,000 筆，UTF-8 或 UTF-8 BOM。以下兩行僅展示欄位格式，不能直接當完整資料匯入：

```csv
date,open,high,low,close,volume
2026-01-02,500.00,505.00,498.00,503.00,50000000
```

最大 2 MiB（HTTP JSON 包裝也有 2 MiB 限制）；日期不可重複；價格必須正值且有限，低價不得高於開／收盤，高價不得低於開／收盤；成交量為非負整數。CSV 匯入無法證實標的，使用者須確保資料與輸入代號一致；介面保留來源標籤。

## 成交與估值

- 歷史重播在第 20 筆收盤後第一次決策；最後一筆沒有下一日可成交，因此不再決策。
- 最新行情判斷使用最後 20 筆資料，只保留判斷，不成交、不計算未發生的獲利。
- 預設手續費每筆 1 美元、滑價 1 基點（0.01%），只是模擬假設，可在新建時修改；費用及滑價各限制為 0–100。
- 買入價 = 隔日開盤 × (1 + 滑價 / 10000)。
- 賣出價 = 隔日開盤 × (1 − 滑價 / 10000)。
- 成交價先以 Decimal、ROUND_HALF_UP 四捨五入到美分；再加扣已四捨五入到美分的費用。
- 買入扣除成交價與費用；賣出收入扣除費用。不允許負現金、負股數。隔日跳空使資金不足時拒絕，不把原 buy 偷改為 sell。
- 帳戶總值 = 現金 + 持股 × 當日收盤價，最後四捨五入到美分。
- 上方總資產旁顯示相對起始本金 10,000 美元的總報酬率：`(總資產 − 起始本金) / 起始本金 × 100%`，顯示到小數點後兩位。已反映模擬手續費與滑價，包含持股按收盤價估值的損益；不是單筆交易的報酬率。
- 持有或拒絕交易均不收費。不在最後一天自動平倉。

原始日線沒有完整股息、拆股及稅務處理，結果是**未調整行情／未計股息的模擬結果**，不是總報酬。含拆股期間不適合據此解讀績效。
模型可能在訓練中接觸過歷史事件；只限制請求的日期不代表完全排除歷史記憶偏差。模型選項機率也不是交易勝率。

## 紀錄、錯誤與證據

`artifacts/trading/<run_id>.json` 保存來源、資料雜湊、行情、費用、帳戶、每次請求、模型回應、耗時、嘗試次數及成交。
CSV 用於查看交易明細，完整來源及 API 證據以 JSON 為準。快取按代號存放於 `artifacts/trading/market-{SYMBOL}.json`，包含資料雜湊與來源；舊 `spy-cache.csv` 僅作 SPY 相容讀取。JSON、CSV 與歷史執行均包含代號，舊版紀錄視為 SPY。

每次請求先記錄意圖，再呼叫模型；逾時或回應無效不自動重試，該次請求可能已被供應商計費，画面停止並要求重新開始。
若開始紀錄都寫不進磁碟，完全不呼叫模型。若模型回應後寫入失敗，停止交易，磁碟可能只留「started」，不能假設請求沒發生。
重複決策、重複推進與過期頁面被版本檢查拒絕。新建模擬不刪除歷史紀錄。

## 程式導覽

| 檔案 | 責任 |
| --- | --- |
| `data.py` | CSV、資料驗證、合成資料、行情 API |

| `decision.py` | Jev Choice 與離線規則 |

| `static/` | 中文 HTML、CSS、JavaScript |

學習順序建議從 `engine.py` 的函式與 Decimal 開始，再讀 `data.py` 的列表／字典與檔案操作，最後看 API 與例外處理。
